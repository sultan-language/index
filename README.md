# index

فهرس حزم لغة السلطان، ويقرؤه سوباكس ليحل اعتماديات مثل `json = "1.2"`. لا يحوي شيفرة الحزم، بل يشير كل إصدار إلى مستودع git والتزام وبصمة محتوى.

The SultanC package index, read by Supax to resolve dependencies such as `json = "1.2"`. It holds no package code: each version points to a git repository, a commit and a content checksum.
