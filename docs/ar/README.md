# فهرس حزم السلطان

هذا المستودع هو الفهرس الذي يقرؤه سوباكس ليحل اعتماديات مثل `json = "1.2"`. لا يحوي شيفرة الحزم: كل إصدار يشير إلى مستودع git والتزام وبصمة محتوى، وتبقى الشيفرة في مستودع صاحبها.

## المحتوى

| المسار | ما فيه |
|---|---|
| `config.toml` | رقم صيغة الفهرس (`version = 1`) |
| `packages/` | ملف لكل حزمة |

## مسار ملف الحزمة

يُبنى المسار من اسم الحزمة بعد تطبيع الهوية (حذف التطويلة، وتوحيد آ وأ وإ إلى ا) وتصغير أحرف ASCII:

| الاسم | المسار |
|---|---|
| محرف واحد | `packages/1/<الاسم>.toml` |
| محرفان | `packages/2/<الاسم>.toml` |
| ثلاثة محارف | `packages/3/<المحرف الأول>/<الاسم>.toml` |
| أربعة فأكثر | `packages/<المحرفان 1–2>/<المحرفان 3–4>/<الاسم>.toml` |
| غير ASCII (العربية وغيرها) | `packages/hash/<أول محرفين من البصمة>/<sha256 الاسم>.toml` |

لا حاجة إلى حساب المسار يدويا: يطبعه `supax package`.

## ملف الحزمة

<div dir="ltr">

```toml
name = "json"

[[versions]]
version = "1.0.0"
git = "https://github.com/someone/sn-json"
commit = "2f3a589624b5a839fe13a27ad52323a4e5edabf4"
checksum = "sha256:80d03f48f971bf104d3f3e46eefaba7c54bfa846be17d257847ec7659fe90680"
```

</div>

| الحقل | معناه |
|---|---|
| `version` | إصدار دلالي، ويطابق `version` في `Supax.toml` عند ذلك الالتزام |
| `git` | رابط المستودع العام |
| `commit` | الالتزام الكامل (40 محرفا ست عشريا) |
| `checksum` | بصمة سوباكس لمحتوى ذلك الالتزام |
| `yanked` | اختياري: `true` يمنع اختيار الإصدار لقفل جديد، ويبقى صالحا لمن قفله |

## إضافة إصدار

1. في مستودع الحزمة: التزم بالتغييرات وادفعها، ثم شغّل `supax package`.
2. يطبع سوباكس مسار الملف ومدخل `[[versions]]`.
3. افتح طلب دمج (PR) يضيف المدخل إلى آخر ذلك الملف، أو ينشئ الملف بسطر `name` في أوله إن كانت الحزمة جديدة.

## القواعد

- يُضاف كل إصدار مرة واحدة ولا يُعدَّل بعد ذلك. التغيير الوحيد المسموح هو إضافة `yanked = true`.
- لا يُحذف إصدار إلا لبرمجية خبيثة أو لسبب قانوني.
- الحزمة الجديدة يقدمها صاحب مستودعها.
- يراجع مشرف الفهرس كل طلب دمج ويدمجه.
